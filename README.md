# Machine Learning Prediction Model

A Machine Learning project for predicting material properties using Python and Scikit-learn.

## Project Overview

This project focuses on applying different Machine Learning regression algorithms to predict material properties from a given dataset.

The complete workflow includes data preprocessing, feature selection, model training, prediction, and performance evaluation.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Machine Learning Models

The project explores different Machine Learning regression models, including:

- Support Vector Regression (SVR)
- Random Forest
- Extra Trees
- Decision Tree
- Gradient Boosting
- K-Nearest Neighbors (KNN)
- Artificial Neural Network (ANN)

## Workflow

1. Data Loading
2. Data Preprocessing
3. Feature Selection
4. Train-Test Split
5. Feature Scaling
6. Model Training
7. Prediction
8. Model Evaluation
9. Model Comparison

## Evaluation Metrics

The models are evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
